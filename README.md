# Outside

Outside is a mobile-first community app for finding outdoor clubs, planning events, and sharing updates with friends.

## Run with Expo

Install dependencies and start the Expo development server:

```sh
npm install
npm start
```

Scan the QR code with Expo Go on a phone, or use `npm run ios` / `npm run android` to open an installed simulator or device. The native app also runs in a browser with `npm run web`.

## Checks

```sh
npm test
npm run typecheck
```

The original Create React App implementation remains available through `npm run legacy:web` and `npm run legacy:web:build`.
